# 🚀 EshaqX Space Mission

> An interactive space-learning and simulation project designed to make
> space science more exciting, understandable, and hands-on.

---

## 🌌 About the Project

**EshaqX Space Mission** is a student-led space science and simulation
project that combines **space exploration, interactive simulations,
rocket missions, planetary science, and educational content**.

The goal is to help students learn about space by **exploring and
experimenting**, rather than only reading information.

---

## 🎯 Project Vision

Our vision is to create an interactive virtual space environment where
users can:

- 🌍 Explore the Solar System
- 🚀 Build and launch rockets
- 🪐 Travel between planets
- 🎯 Plan space missions
- 🛰️ Explore mission systems
- 📚 Learn space theories
- 🧪 Perform virtual space experiments
- 🔭 Discover astronomy and space science

We want to make space science **interactive, educational, and enjoyable**.

---

### 🌍 Solar System Explorer

Explore planets and learn about their:

- Atmosphere

# 🧪 Virtual Space Experiments

The Virtual Space Experiments module allows users to change variables,
run simplified physics simulations, and observe the results.

### Experiments

#### 🌍 Gravity Experiment
Explore how gravity changes with mass and distance.

#### 🛰️ Velocity & Motion
Change initial velocity and observe how the trajectory changes.

#### 🚀 Escape Velocity
Experiment with spacecraft velocity and determine whether an object
remains gravitationally bound or can escape in the simplified model.

#### 🔥 Rocket Thrust vs Gravity
Change rocket mass, thrust, throttle, and planetary gravity to explore
launch performance.

#### 🌎 Earth vs Mars
Compare simplified launch conditions between Earth and Mars.

### Experiment Flow

**INPUT → SIMULATION → RESULTS → SCIENTIFIC EXPLANATION**

The experiments are designed for education and use simplified models where
appropriate. They are not intended to provide exact predictions for
real spacecraft missions.
